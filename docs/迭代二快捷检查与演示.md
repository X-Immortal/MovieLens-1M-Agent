# 迭代二检查与演示

## 演示前检查

按 [README](../README.md)完成数据、API 配置和模型准备，在项目根目录执行：

```bash
./run.sh
docker compose ps
curl -fsS http://localhost:8501/health
docker compose exec -T movielens-agent python3 -m unittest -v test_agent test_iteration2 test_sessions
```

健康端点应返回 `ok`。打开“分析资料 → 数据与模型”，核对数据版本、模型版本、T1/T2 和训练、验证、测试数量。联网检查命令见 README，执行时会产生 API 用量。

## 约 7 分钟的演示

| 操作 | 示例问题或操作 | 观察内容 |
| --- | --- | --- |
| 确认数据与模型，约 30 秒 | 打开“分析资料 → 数据与模型” | 版本、时间边界和数据切分 |
| 分类预测，约 1 分钟 | 用逻辑回归预测用户 1 对电影 1 是否打高分。 | 概率、类别、阈值和测试指标 |
| 多轮追问，约 1 分钟 | 同一个用户和电影，换成决策树。随后问：两个概率为什么不同？ | 编号继承、算法切换和基于结果的解释 |
| 聚类与降维，约 2 分钟 | 比较用户 1、2、3 在两种聚类算法中的归属。随后问：再比较这些用户的 PCA 与 SVD 二维坐标。 | 两组归属、画像样例、坐标图、分量权重和聚类对照 |
| 组合请求，约 1 分钟 | 预测用户 1 对电影 1 是否打高分，再查看该用户的群体，每类对照两种算法。 | 同一次请求调用分类和聚类工具 |
| 异常与参数，约 1 分钟 | 新会话输入：用决策树预测用户 2 是否打高分。随后补充：电影 3。再查询一个未保存的降维维数。 | 缺少编号时追问，结果未生成时说明原因 |
| 获取产物，约 30 秒 | 下载实验报告、坐标 CSV 和散点图 PNG | 文件可下载，图表含图例和实验版本 |

每次分析后展开“分析依据”，查看调用参数、模型配置、时间切分及结果依据。历史会话支持刷新后继续追问，并可通过列表右侧按钮删除。

## 质量评估与结果解释

需要展示迭代一能力时，输入“查看清洗前后的五维质量、异常处置和清洗后数据样例”。主结果展示评分和处置计数，“分析依据”展示评价口径、异常原始行和清洗样例。

讲解时区分以下口径：

- 预测概率对应指定用户与电影；测试指标评价独立时间段上的模型表现。
- 画像和坐标来自训练期模型；指定用户集合只筛选已有结果。
- 方差比例衡量投影保留的方差；降维前后的轮廓系数在各自空间计算。
- 修复、去重和隔离是不同的数据处置方式。
- 未保存的维数或群数需要训练新的实验。

展示数值以页面正在使用的实验为准。报告中的实验结果与设置见[实验报告](迭代二实验报告.md)。
