## 约 7 分钟的现场演示

1. **准备和版本，约 1 分钟。** 打开 <http://localhost:8501/>。指出右侧清洗数据版本、实验标识、`T1/T2` 与三段数据量；说明训练只用 `T1` 前评分，验证期选参数，`T2` 后测试期做最终评价。
2. **分类，约 1 分钟。** 新建对话，输入 `预测 UserID 1 对 MovieID 1 是否打高分`。展示 `Toy Story (1995)` 的两种实际高分概率、测试 F1/ROC-AUC，以及训练期组合的样本内提示。再问 `为什么？`，展示基于已保存结果的解释。
3. **聚类，约 1 分钟。** 输入 `查看 UserID 1 的 K-Means 和层次聚类群体`。当前结果分别为 0 群、2 群；展示 6,039 位训练期用户、群体偏好、代表用户和较低的轮廓系数，避免把群体标签说成用户固定身份。
4. **降维与聚类对照，约 2 分钟。** 输入 `比较 PCA 与 SVD 的二维降维结果`。展示两张真实坐标图、`38 → 2` 维、约 `18.677%` 的解释方差比例、重构误差、矩阵与坐标数组大小，以及四行原空间 / 二维空间聚类对照。说明轮廓系数来自不同距离空间，不能当作信息保留率。
5. **参数和失败边界，约 1 分钟。** 输入 `查看用户 1、2、3 的 PCA 降维，用 K-Means k=4 对照，信息保留至少 20%`。指出三个用户的坐标和阈值未达标提示。再输入 `用 PCA 降维，K-Means k=5 对照`，展示“当前只保存 4 群”的失败说明，证明系统不会编造新实验结果。
6. **证据文件，约 1 分钟。** 在右侧打开模型实验报告下载入口，说明 `report.json` 记录算法参数、版本、时间边界和评价指标；用户画像、群体归属与二维坐标 CSV 可供迭代三读取。

联网演示可选：输入 `What segment is UserID 1 in?`，已于 2026-10-21 实测 DeepSeek 意图识别调用两种聚类工具；现场网络或外部 API 不可用时，使用上述确定性中文问题即可展示核心 Agent 能力。

## 需要如实说明的边界

- 当前只查询已登记模型。请求未保存的群体数量或目标维数会明确失败；信息保留阈值用于核对现有模型，不会在一次问答中自动训练到达标。
- 指定用户集合时返回已有模型中的坐标或群体归属；聚类质量对照仍基于全体训练期用户，不对所选子集重新拟合。
- 本次快捷检查没有重新执行耗时的 Hadoop 清洗或模型训练。已有独立 Hadoop 回归和训练证据见[迭代二实验报告](迭代二实验报告.md)。
- 当前课程目录只找到分类 PPT，尚未找到聚类与降维的对应 PPT，因此“六种算法是否都出自相应 PPT”这一条仍需在教师提供材料后核对。不能将它写成已确认满足。
